# RIPTIKA
1. Backend: cd backend; cp .env.example .env; fill keys; npm i; npm start
2. Android: open this folder in Android Studio (JDK 17), let Gradle sync, Run.
3. In app: Settings -> Backend URL (emulator: http://10.0.2.2:8787, phone: your PC/server IP), App token = APP_TOKEN.
4. Optional: Settings -> Enable screen reading, turn on RIPTIKA in Accessibility.
